# FSVNG Helper — Шпаргалка законодательства (Russia Online)

Скрипт на базе **AutoHotkey v1.1**, создающий компактный полупрозрачный HUD-оверлей поверх игры с быстрой выжимкой нормативно-правовой базы для сотрудников правоохранительных органов (ФСВНГ / МВД / ФСБ) на проекте **Russia Online**.

---

## 📌 Что внутри

Скрипт выводит информационные подсказки в левый верхний угол экрана без потери фокуса игры (`NoActivate`):

* **Уголовный кодекс (УК РО):** ключевые статьи, сроки (звёзды) и суммы штрафов.
* **Кодекс об административных правонарушениях (КоАП РО):** основные административные статьи, аресты (сутки) и штрафы.
* **Уголовно-процессуальный кодекс (УПК РО):**
  * Основания для задержания (ст. 51 ч. 1, ч. 3);
  * Пошаговый регламент задержания и текст правила Миранды (ст. 52);
  * Субъекты задержания и правила оцепления (ст. 54).

---

## ⌨️ Горячие клавиши

Каждое окно открывается и закрывается повторным нажатием соответствующей клавиши (Toggle):

| Клавиша | Раздел | Описание |
| :---: | :--- | :--- |
| **`F4`** | **Уголовный кодекс** | Основные статьи УК (убийство, побои, оружие, наркотики, взятки, неповиновение и др.) |
| **`F5`** | **КоАП** | Административные статьи (оскорбление, хулиганство, дискредитация, оружие и др.) |
| **`F6`** | **УПК — Часть 1** | Статья 51: основания задержания, порядок действий при отказе показать документы |
| **`F7`** | **УПК — Часть 2** | Статья 52: пошаговый порядок задержания + текст правила Миранды |
| **`F8`** | **УПК — Часть 3** | Статья 54: субъекты задержания (кто имеет право находиться рядом) |

## 🚀 Установка и запуск

### 1. Установка AutoHotkey
Скрипт написан с использованием синтаксиса **AutoHotkey v1.1**:
1. Перейдите на официальный сайт: [autohotkey.com](https://www.autohotkey.com/).
2. Скачайте и установите **AutoHotkey v1.1 (v1 deprecated/current)**.

### 2. Запуск скрипта
1. Склонируйте репозиторий или скачайте файл `fsvng_ahk.ahk`:
   ```bash
   git clone [https://github.com/cowboy-marlboro/russia-online-fsvng.git](https://github.com/cowboy-marlboro/russia-online-fsvng.git)
   ```

> ⚠️ **Обязательно:** нажмите правой кнопкой мыши по `fsvng_ahk.ahk` → **«Запуск от имени администратора»** (иначе окно игры с античитом перехватит функциональные клавиши и оверлей не откроется).

2. В игре нажимайте клавиши **`F4`–`F8`** для открытия нужного раздела.
3. Чтобы закрыть подсказку, нажмите ту же клавишу ещё раз.

## 🎨 Настройка отображения

Если у вас нестандартное разрешение или окно перекрывает элементы интерфейса игры, параметры можно изменить в коде:

* **Позиция окна:** параметр `Gui, Show, x5 y1 NoActivate`
  * `x5` — отступ слева в пикселях.
  * `y1` — отступ сверху в пикселях.
* **Прозрачность фона:** строка `WinSet, TransColor, %CustomColor3% 180`
  * Значение `180` можно менять от `0` (полностью прозрачный) до `255` (глухой черный фон).
* **Размер и цвет шрифта:** строка `Gui, Font, s7 cWhite w1000`
  * `s7` — размер кегля (шрифта).
  * `w1000` — жирность (bold).
