# FSVNG Helper — Шпаргалка законодательства и Дисциплинарного устава (Russia Online)

Специализированный скрипт на базе **AutoHotkey v1.1**, создающий компактный полупрозрачный HUD-оверлей поверх игры с быстрой выжимкой нормативно-правовой базы для личного состава и сотрудников **Отдела собственной безопасности (ОСБ) ФСВНГ** на проекте **Russia Online**.

Оверлей выводится в левый верхний угол экрана поверх всех окон без перехвата фокуса ввода игры (`NoActivate`).

---

## 📌 Что входит в шпаргалку

1. **Уголовный кодекс (УК РО):** ключевые статьи, сроки заключения (звёзды) и штрафы.
2. **Кодекс об административных правонарушениях (КоАП РО):** основные административные статьи, аресты (сутки) и штрафы.
3. **Уголовно-процессуальный кодекс (УПК РО):**
   * Основания задержания (ст. 51 ч. 1, ч. 3);
   * Регламент процесса задержания и текст правила Миранды (ст. 52);
   * Субъекты задержания и правила оцепления (ст. 54).
4. **Дисциплинарный устав ВС / ФСВНГ (Повседневный надзор ОСБ):**
   * Прогулы, СОЧ, форма одежды, поведение на плацу и в казарме, субординация, правила связи и обращение с оружием.
5. **Дисциплинарный устав ВС / ФСВНГ (Антикоррупция и тяжкие проступки):**
   * Превышение полномочий, взятки, использование положения в личных целях, слив гостайны, связи с ОПГ, хищения и фальсификация документов.

## ⌨️ Раскладка горячих клавиш

Каждое окно работает в режиме переключателя (Toggle): **нажали клавишу — окно открылось, нажали повторно — закрылось**.

| Клавиша | Раздел | Описание |
| :---: | :--- | :--- |
| **`F4`** | **ДУ — Быт и служба (ОСБ)** | Ст. 6–47.4, 70.1–92: форма, КПП, СОЧ, плац, казарма, субординация, рация |
| **`F5`** | **ДУ — Преступления (ОСБ)** | Ст. 56–87: взятки, превышение прав, связи с криминалом, утечка данных, халатность |

## 🚀 Установка и запуск

### 1. Установка интерпретатора AutoHotkey
Скрипт разработан под версию **AutoHotkey v1.1**:
1. Перейдите на сайт [autohotkey.com](https://www.autohotkey.com/).
2. Скачайте и установите **AutoHotkey v1.1 (v1 current/deprecated)**.

### 2. Загрузка проекта
* Клонируйте репозиторий через Git:
  ```bash
  git clone [https://github.com/cowboy-marlboro/russia-online-fsvng.git](https://github.com/cowboy-marlboro/russia-online-fsvng.git)
  ```
* Либо скачайте архив с кодом через кнопку **Code** $\rightarrow$ **Download ZIP** и распакуйте в удобную папку.

### 3. Запуск скрипта

> ⚠️ **Обязательно:** нажмите правой кнопкой мыши по `fsvng_ahk.ahk` $\rightarrow$ **«Запуск от имени администратора»** (иначе окно игры с античитом перехватит функциональные клавиши и оверлей не откроется).

После запуска в системном трее (рядом с часами Windows) появится зелёная иконка **H**. Перейдите в игру и вызывайте подсказки по клавишам **`F4`–`F10`**.

## 🎨 Настройка отображения

Если у вас нестандартное разрешение монитора или оверлей перекрывает элементы интерфейса:

* **Позиция на экране:** редактируется параметром `Gui, Show, x5 y1 NoActivate` (или `Gui, DU1:Show, x5 y1 ...`):
  * `x5` — отступ слева в пикселях.
  * `y1` — отступ сверху в пикселях.
* **Прозрачность подложки:** строка `WinSet, TransColor, %CustomColor% 180`:
  * Значение `180` можно регулировать от `0` (полностью невидимый фон) до `255` (глухой сплошной черный цвет).
* **Размер текста:** строка `Gui, Font, s7 cWhite w1000`:
  * `s7` — размер шрифта.
  * `w1000` — жирность начертания (Bold).
